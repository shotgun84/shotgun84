## Things I've built

- **TinyLM**: a 13M-parameter language model on my own architecture, built for story writing. Pre-trained on TinyStories and conversational data, then fine-tuned on SmolTalk for dialogue.
- **[PyRust](https://github.com/shotgun84/pyrust)**: rename `script.py` to `script.pyr` and the parts that can compile run as native code through Rust, up to 80x faster. No decorators, no type annotations, no new syntax.
- **The Expert**: an agentic red-team tester. Point it at an endpoint and it runs hundreds of iterative tests, then writes up the bugs and vulnerabilities it found.
- **[GeoSentinel](https://github.com/shotgun84/Geosentinel)**: a 3D globe of live natural disasters, pulling earthquakes, wildfires, storms and alerts from NASA EONET, USGS and GDACS.
- **QuantMonitor**: a stock research engine. Subagents handle deep research, technical analysis and sentiment, and it returns one investment report for the ticker you give it.
